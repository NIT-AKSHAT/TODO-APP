# 🚀 Todo App

A simple, interactive and responsive Todo Application built using **HTML, CSS and Vanilla JavaScript**.

Manage daily tasks, track completion progress and keep your tasks saved even after refreshing the browser.

## 🌐 Live Demo

[**View Live Project →**](https://NIT-AKSHAT.github.io/TODO-APP/)

## ✨ Features

- ➕ Add tasks with a title and description.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks whenever needed.
- 💾 Persistent data storage using LocalStorage.
- 📊 Real-time task count and completion percentage.
- 🔄 Automatically restores saved tasks after refreshing the page.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and layout |
| JavaScript | Application logic and interactivity |
| DOM Manipulation | Dynamic UI updates |
| LocalStorage | Persistent client-side data storage |

## ⚙️ Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/NIT-AKSHAT/TODO-APP.git
```

**2. Navigate to the project directory**

```bash
cd TODO-APP
```

**3. Open `index.html` in your browser.**
